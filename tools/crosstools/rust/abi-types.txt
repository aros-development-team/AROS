# Types the AROS port of the Rust libc crate defines (src/unix/aros/mod.rs),
# checked against the AROS C headers by abicheck.sh: size and alignment
# must match, or Rust code passes C a buffer of the wrong size (a stale
# pthread_attr_t once made every std::thread::spawn overwrite its caller's
# frame).
#
# <rust type> | <C type> | <headers> [| opaque | rust]
# The Rust type is looked up as libc::<rust type>. Add a line for every
# type the libc patch adds or changes.
#   opaque  Rust models the type as an opaque block (only handled through
#           pointers, sized for the largest AROS build): Rust's size and
#           alignment must be at least C's, not equal.
#   rust    the layout is the Rust side's own (the crosstool's libc converts
#           to and from the C one, e.g. getaddrinfo()): listed, not compared.
